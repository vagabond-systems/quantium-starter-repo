### Set-up Python virtual enviornment
https://realpython.com/python-virtual-environments-a-primer/#how-can-you-work-with-a-python-virtual-environment

- python3 -m venv folderName/ [in VS Code terminal]
Creates new python virtual environment

- cd.. [back to root directory]

-  source folderName/bin/activate [in VS Code terminal]
activates new python virtual environment : should get ouput as: `(venv) ....`



### Dash and Pandad installation
https://dash.plotly.com/installation

- Dash:
[popular open-source python library making web based data visual interfaces (e.g. dashboards) using python]
run command: `pip install dash --upgrade pip` [installs latest version of dash]
output should be: `Successfully installed pip-25.2`

run command: `pip install "dash[testing]"` [install testing dependencies]
outpu: `Successfully installed PySocks-1.7.1 attrs-25.3.0 beautifulsoup4-4.14.2` ....

- Pandas: 
[popular open-source python library for data analysis/cleansing/manipulation/experimentation etc.]
run command: `pip install pandas --upgrade pip` [installs latest version of pandas]
output should be: `Successfully installed numpy-2.3.3 pandas-2.3.3` .....
